What this model does differently

Every other model in this repository classifies one 3-second trial in isolation. This one encodes each trial to a single 64-dimensional vector with an EEGNet-style convolutional front end, then runs transformer self-attention over a group of 64 trials from the same person and emits a Focus/Distractor label for every trial in the group at once.

The reason to expect a gain is that a subject-independent split hands the network a person it has never seen, whose amplitude scale and electrode impedances are unknown. A single trial gives it no way to separate the effect from the person. 64 trials seen together let attention estimate the common part and subtract it — an unsupervised, test-time, per-subject calibration that a per-trial model structurally cannot perform.

No positional embedding, and no CLS token. The trials in a context are a set, not a sequence: they are drawn at random from one person's session, so slot 12 sitting next to slot 40 means nothing. Every token is an answer, so there is nothing to summarise.
This is transductive inference — read the number with that in mind. To classify one trial at context 64, the model needs 63 other trials from the same person available at the same time. It never sees their labels, so there is no leakage, but it is not a drop-in replacement for a per-trial classifier: it cannot label the very first trial of a session in isolation. It fits a workflow where a block of trials is scored after the fact, and does not fit one that must emit a verdict the instant each trial ends. Context 1 is the number to quote for that second case, and it is measured here on exactly the same folds.
Permutation equivariance: max |Δ| = 3.6e-07. Shuffling the trials in a context permutes the predictions and changes nothing else — the model treats the context as a set, which is what having no positional embedding is supposed to buy.

Tensor shapes — traced through the real model

Does attending across trials help?

Context size 1 is the ablation: the identical architecture with a context of one, where self-attention over a single token is the identity and the model collapses to a plain per-trial classifier. The difference between the two ends of this curve is the entire effect of cross-trial attention, measured with everything else held fixed — same folds, same encoder, same optimiser, same number of trials per optimiser step.

Cross-trial attention does not help on this dataset: ΔAUC = -0.000, against a between-fold spread of ±0.036. The curve is flat from context 1 to context 64, and the difference is far inside the noise. Re-grouping the same test trials into different contexts moves an individual prediction by only 0.014 in probability, so the model is very nearly ignoring its context outright.

Why, most likely. The calibration this architecture was built to perform has already been done to the data before the model sees it. 07_bands.py z-scores every channel per subject — verified in the discovery table at the bottom of this page — so each person's amplitude scale and electrode impedances are already divided out. That per-subject nuisance variance was exactly the quantity attention across a person's trials could have estimated and removed, and it is gone by the time the encoder runs. What is left is a time-locked evoked response inside each individual 3-second trial, and neighbouring trials carry no extra evidence about it.

The result is worth having as a measurement rather than a disappointment: it says the per-subject normalisation already in this pipeline is doing the work, and that a heavier set-level model is not where the remaining headroom is.

The shortcut stress test

A set model handed 64 trials that are roughly half Focus can cheat: rank them by some internal score and call the top half Distractor. That posts a good AUC while learning nothing about any individual trial. This table rebuilds the test contexts at fixed compositions, including contexts where every single trial carries the same label — where a median split is guaranteed to be half wrong.

Passes — decisively. AUC stays within [0.775, 0.777] — a spread of 0.002 — across every composition from 90/10 to 10/90. A model that ranked the context and split at the median would have its ordering dictated by the composition and could not hold one AUC across all of them. The ordering here is a property of the individual trials. Recall on a context where every trial shares one label is 0.626, against 0.701 at the natural composition — a 0.075 slide of the 0.50 threshold, not of the ranking.

How much does the answer depend on which neighbours a trial got?

Re-scoring the whole test set under 5 independent random context assignments: AUC 0.777 ± 0.001 within a fold, and an individual trial's predicted probability moves by 0.014 on average depending on which neighbours it was grouped with. The headline table uses one fixed, seeded assignment.

Control window — the leakage guardrail

0.0–2.0 s, before the notification. The two conditions are physically identical here, so any real skill in this window would be a bug. For this model the control does double duty: it also checks that the act of grouping trials into contexts does not by itself carry label information.
