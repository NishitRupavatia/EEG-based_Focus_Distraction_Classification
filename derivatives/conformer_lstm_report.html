Architecture

The tokenizer and the Conformer block are the same objects as in 11_conformer_transformer.py, imported from the same module. The only change is what consumes the token sequence: a bidirectional LSTM instead of a reduction stage plus transformer blocks. So the gap between the two models' numbers is the sequence model and not a re-tuned network.

Three consequences. Attention costs ~4d² per block whatever the sequence length, so the sibling spent 17,088 parameters attending over 13 tokens where a BiLSTM does the job for 9,600 and scales with length, which is 36 here. Recurrence is order-aware by construction, so there is no positional encoding at all — which is why the parameter count is identical for the 375-sample main window and the 250-sample control window. And classifying a fixed-length, time-locked window is an integrate-in-order problem, which is the prior recurrence encodes directly.
