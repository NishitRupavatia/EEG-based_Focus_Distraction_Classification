Architecture

Every other network here either convolves and then attends, or does one without the other. This one puts a depthwise convolution inside every attention block (Gulati-style Conformer: ½FFN → self-attention → conv → ½FFN), so local shape and global context are refined together at each depth rather than local structure being fixed up front.

Tokens are time, never channels — the 15 electrodes are collapsed by a depthwise spatial convolution in the tokenizer, as in EEGNet. The trial becomes 36 overlapping patches of 25 samples (0.20 s) every 10 (0.08 s), the Conformer stage runs at that resolution, and a strided reduction hands the Transformer stage 12 tokens with a learned absolute positional embedding and a CLS token.

Control window — the leakage guardrail

0.0–2.0 s, before the notification. The two conditions are physically identical here, so any real skill in this window would be a bug. Because the readout is a CLS token rather than a flatten, the control model has the same parameter count as the main one bar the positional table — so this is a like-for-like comparison.
