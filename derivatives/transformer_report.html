Architecture

Attention runs over temporal tokens: the trial is cut into 25-sample (0.20 s) slices, each flattened across all 15 electrodes and projected to a 64-d token. Channels are never the sequence. A learnable positional embedding is added to the 16-token sequence before the first encoder block, and a CLS token carries the classification.

Tensor shapes — traced through the real model, batch 64

  input                        [B, C, T]   (64, 15, 375)
  patches       [B, N, C x patch_size]     (64, 15, 375)
  patch projection             [B, N, D]   (64, 15, 64)
  + CLS + positional         [B, N+1, D]   (64, 16, 64)
  transformer encoder        [B, N+1, D]   (64, 16, 64)
  CLS token                    [B, D]      (64, 64)
  classifier                      [B, 2]   (64, 2)
3 pre-norm encoder blocks · 4 heads · MLP 64→256→64 · dropout 0.5 · 175,490 trainable parameters. No convolution anywhere in the model — that is the point of the comparison.
